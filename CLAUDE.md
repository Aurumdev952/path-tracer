# Path Tracer

## Focus

Path Tracer is a personal, experimental project. The current goal is to make the core tech work reliably:

- recording a route,
- finding its sign photos again,
- placing and aligning the route,
- detecting floor changes,
- drawing the AR guidance.

Choose reliability and accuracy of that core loop over reach and polish.

Out of scope unless the owner asks for it:

- support for more devices (phones without ARCore, iPhone),
- localisation and multiple languages,
- accessibility work,
- onboarding and UX for non-technical users,
- distribution and business features (building operators, route stores).

When you review, plan or file issues, leave out-of-scope findings out. If they are worth noting, list them separately as deferred.

## GitHub issues

- Before you create issues, list the proposed issues (title, labels, short summary) and wait for the owner's approval.
- Use the existing phase labels (`phase 1: prove it` to `phase 4: later`) and `bug`. Add new issues to the "Path Tracer roadmap" project.
